# 🚀 DevOps & Git для Data Scientists

Интерактивное мини-приложение, которое объясняет основные концепции разработки и версионирования кода.

## 📚 Что здесь объясняется?

- **Git & Version Control** — как работает система контроля версий
- **GitHub & Collaboration** — как работать в команде
- **API & Webhooks** — как разные приложения общаются между собой
- **Docker** — контейнеризация приложений
- **CI/CD** — автоматизация тестирования и деплоя
- **package.json** — управление зависимостями
- **.gitignore** — исключение файлов из версионирования

## 🚀 Быстр��й старт

### Требования
- Node.js 18+
- npm или yarn

### Установка и запуск

```bash
# 1. Клонируешь репозиторий
git clone https://github.com/Shmel131/experimental.git
cd experimental

# 2. Устанавливаешь зависимости
npm install

# 3. Запускаешь dev-сервер
npm run dev

# 4. Открываешь http://localhost:3000
```

## 💡 Почему это важно для Data Scientists?

Даже если ты работаешь с ML моделями, нужно понимать:

- **Git** — совместная разработка и история изменений
- **API** — как подавать результаты моделей в веб-приложение
- **Docker** — деплой ML сервисов одинаково на разных машинах
- **CI/CD** — автоматическое тестирование моделей при каждом коммите
- **package.json** — управление библиотеками (numpy, pandas, tensorflow и т.д.)
