Почему это важно

Умение понимать разработку — это навык, который помогает и в ML, и в реальном продукте.

Даже если ты делаешь Data Science, тебе рано или поздно встретятся Git, репозитории, API для моделей, Docker, CI/CD и автоматизация. Эти вещи помогают делать проекты воспроизводимыми, масштабируемыми и готовыми к реальному использованию.

  • Git — история изменений и командная работа
  • API — способ общаться с сервисом
  • Docker — одинаковый запуск везде
  • CI/CD — автоматизация и деплой

Когда что использовать

          


          

            

              
Git vs GitHub

              

                Git — это инструмент локально. GitHub —
                сервис для хранения, совместной работы и review pull request.
              

            

            

              
API vs Webhook

              

                API — вы сами делаете запрос. Webhook —
                сервис сам приходит к вам и сообщает о событии.
              

            

            

              
Docker vs обычный запуск

              

                Docker даёт одинаковую среду. Это важно, когда “у меня работает, а у вас нет”.
              

            

            

              
CI/CD vs ручной деплой

              

                Автоматизация уменьшает ошибки, ускоряет релизы и делает процесс стабильнее.
